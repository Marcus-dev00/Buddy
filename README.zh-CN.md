<h1 align="center">Buddy</h1>

<p align="center">
  <a href="README.md">English</a> · <a href="README.zh-CN.md">简体中文</a>
</p>

**Buddy** 是一个轻量常驻 Windows 桌面的极简灵动岛 AI 伴侣。平时它是一枚安静悬浮在屏幕边缘的黑色胶囊，陪你听歌、打盹；点开或拖入文件，随时变成你的桌面 AI 助手。

## 下载

前往 **[Releases 页面](https://github.com/Marcus-dev00/Buddy/releases/latest)** 下载最新 Windows 安装包即可使用，支持应用内自动检测与一键更新。

## Buddy 能做什么

- **自由摆放 & 四边磁吸** — 无论是胶囊还是展开面板，都可以随意拖到多屏幕任意位置；靠近屏幕四边会自动磁吸贴边，头部朝向和展开方向也会自动适配。
- **自然神态 & 音乐律动** — 悬停时眼神会跟随光标，空闲时慢慢打盹；播放系统音乐时，音符与波形随节拍律动，眼睛跟着轻摆而对话框保持稳定。
- **多模型对话 & 5 档思考深度** — 支持 OpenAI 兼容、Anthropic 与 Gemini 模型，提供 `Off` 到 `Max` 五档思考深度切换及可折叠思考过程。
- **文件拖放 & 桌面助手** — 直接把文件、图片或文件夹拖给 Buddy 即可阅读分析；开启桌面 Agent 后，可在每次操作前经你确认帮你整理、修改和执行任务。
- **7 天记忆库 & 快捷截图** — 自动本地收录剪贴板与截图（支持全文检索与星标永久保存），支持全局快捷键 `Alt + Shift + S` 一键框选截图提问。
- **本地加密隐私** — API 密钥通过 Windows DPAPI 本地加密保存，聊天与记忆数据全程留在本地。
